A block-based learning aid for building and taking apart Kalaallisut words. Prototype — nothing here is authoritative.

Drag morpheme blocks from the palette and snap them into a single stack, stem first. The result updates as you build.

Type a real Kalaallisut word and see it broken into a morpheme chain. The chain is read-only — a verified rebuild, not a guess.
